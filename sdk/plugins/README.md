# SDK Plugins

Official SDK plugins are grouped here because they are shipped as the SDK product
itself.

- `core`: root `sdk.dll` plugin and host integration.
- `runtime`: game runtime probes, events, and mutation application.
- `data`: OPPW4 data service and generated data API.
- `rdb`: RDB service facade and patcher implementation.
- `linkdata`: LinkData service.
- `debug`: developer diagnostics.
- `overlay`: debug overlay.
