# Roadmap

## Current Direction

- Registry-first SDK architecture.
- QuickJS as the main mod runtime.
- Rust plugins as the native extension path.
- Native Rust mods as experimental advanced support.

## Next Milestones

1. Finish runtime event/mutation contracts in `bridges/core`.
2. Publish official JS examples for runtime, RDB, and LinkData workflows.
3. Split `sdk_runtime` internals into events, modules, probes, and apply layers.
4. Add package validation that rejects stale language-specific artifacts.
5. Add Windows test jobs for hook-linked crates.
