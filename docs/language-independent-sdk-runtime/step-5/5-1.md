# Step 5.1 - IA 8 - Packaging Et Test Jeu Launchable

## Objectif

Verifier que le nouveau socle peut etre package et installe dans le jeu sans
toucher au loader, puis laisser une hypothese testable activee.

## Contexte a lire

- `tools/package-sdk.ps1`
- `docs/HANDOFF-2026-05-25-runtime-rank-difficulty-rewards.md`
- `official_plugins/sdk/runtime/plugin.toml`
- `official_plugins/sdk/runtime/src/config/defaults.rs`

## Fichiers a modifier

- Modifier si besoin: `tools/package-sdk.ps1`
- Modifier si besoin: `official_plugins/sdk/runtime/src/config/defaults.rs`
- Creer: `docs/language-independent-sdk-runtime/step-5/output/5-1-game-test.md`

## Travail

1. Build release avec MSVC.
2. Package SDK sans remplacer `dinput8.dll`.
3. Copier les plugins vers `D:\SteamLibrary\steamapps\common\OPPW4`.
4. Activer une seule hypothese:
   - rewards event logs actifs;
   - mutation Berry test seulement si elle est explicitement configuree.
5. Documenter exactement ce que le joueur doit faire en jeu.
6. Apres test, lire logs runtime et crash logs avant toute correction.

## Commandes attendues

Build:

```powershell
cargo build --release
```

Package:

```powershell
.\tools\package-sdk.ps1 -NoLoader
```

Installation:

```powershell
Copy-Item -Path .\dist\plugins\* -Destination D:\SteamLibrary\steamapps\common\OPPW4\plugins -Recurse -Force
```

## Hypothese testable

Lancer une mission qui arrive au result screen. Attendu:

- le jeu demarre;
- le result screen ne crash pas;
- le log `sdk_runtime` contient `reward_event`;
- si mutation activee, le log contient `reward_mutations` puis l'effet Berry.

## Verification

Lancer avant installation:

```powershell
cargo test
cargo build --release
```

Apres test jeu, lire:

```text
D:\SteamLibrary\steamapps\common\OPPW4\plugins\sdk\logs\sdk_runtime\*.log
```

## Definition of done

- Le jeu est launchable.
- La feature activee a produit un log exploitable.
- Aucun crash n'est ignore.
- Le fichier `output/5-1-game-test.md` contient le resultat du test.
