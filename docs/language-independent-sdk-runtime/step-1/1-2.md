# Step 1.2 - IA 2 - Types Core Runtime

## Objectif

Ajouter les types Rust du coeur runtime pour rewards, rank, difficulty et player
sans encore brancher les hooks. Les types doivent etre independants de Lua.

## Contexte a lire

- `docs/LANGUAGE-INDEPENDENT-SDK-RUNTIME.md`
- `official_plugins/sdk/runtime/src/rewards/rules.rs`
- `official_plugins/sdk/runtime/src/rewards/commit_hook.rs`
- `official_plugins/sdk/runtime/src/mission/rank/control.rs`
- `official_plugins/sdk/runtime/src/mission/difficulty/control.rs`

## Fichiers a creer ou modifier

- Creer: `official_plugins/sdk/runtime/src/runtime/core/mod.rs`
- Creer: `official_plugins/sdk/runtime/src/runtime/core/rank.rs`
- Creer: `official_plugins/sdk/runtime/src/runtime/core/rewards.rs`
- Creer: `official_plugins/sdk/runtime/src/runtime/core/difficulty.rs`
- Creer: `official_plugins/sdk/runtime/src/runtime/core/player.rs`
- Modifier: `official_plugins/sdk/runtime/src/runtime/mod.rs`

## Travail

1. Creer `runtime::core`.
2. Definir `RankValue` avec slots `0..5` et aliases de debug.
3. Definir `RewardCommitEvent`.
4. Definir `RewardMutation`.
5. Definir `RewardState` minimal avec berry optionnel et champs extensibles.
6. Definir `DifficultySnapshot` minimal avec mission, mode et difficulty.
7. Definir `PlayerSnapshot` minimal avec active character ids.

## Contraintes

- Pas de `mlua` dans `runtime/core/*`.
- Pas de pointeurs bruts exposes dans les types publics du core.
- Les noms doivent etre modder-facing: `rank`, `berry`, `mission_id`.
- Les noms reverse restent seulement en commentaire court si utile.

## Tests a ajouter

Ajouter des tests unitaires dans les nouveaux fichiers:

- `RankValue::from_slot(5)` donne `SPlus`.
- `RankValue::from_slot(9)` donne `Unknown(9)`.
- `RewardMutation::MultiplyBerry(2.0)` est stockable dans un vec.
- `RewardCommitEvent` peut etre construit sans mission connue.

## Verification

Lancer:

```powershell
cargo test -p oppw4-sdk-runtime-plugin runtime::core
cargo test
```

Resultat attendu: tous les tests passent.

## Definition of done

- Les types core existent.
- Aucun hook n'appelle encore ces types.
- Aucun code Lua ne depend directement de ces types dans cette tache.
